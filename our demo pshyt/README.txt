AMIRITO FRONTEND ASSIGNMENT DEMO

1. Extract the ZIP file.
2. Open index.html in your browser. For easiest local development, open the folder in VS Code and use the Live Server extension.
3. Sign in from login.html. Choose Customer or Admin to view the relevant pages.
4. Customer: open Menu, add products to cart, tap Checkout, submit delivery details, then print the receipt.
5. Tap the heart to add favourites. Account and order history pages show the saved demo data.
6. Admin: sign in as Admin, add or remove products, view orders, mark orders picked/completed, and see the demo balance.

IMPORTANT LIMITATIONS:
- No backend, MySQL, real authentication, payment processing, or cross-device data sync is included.
- Products, cart, favourites, user demo info and orders are saved in the browser localStorage. Clearing browser storage clears the demo data.
- The assignment's feature says price 50–500p; the slider currently uses 50–500 in the displayed currency. If your teacher means pence, change the currency label and prices accordingly.
- The frontend role dropdown is only a demonstration and is not secure. A real application must enforce permissions server-side.
- The demo balance adds order item values when an order is marked completed.
